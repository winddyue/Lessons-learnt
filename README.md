# Lessons Learnt

这个仓库用于保存课程学习证据、结构化笔记，以及从学习中沉淀出的可复用方法论。

当前主线：**生成式软件工程（NJU Raw26）**。

## 仓库原则

1. 原始字幕是证据层，不直接等同于结论。
2. 每节课先形成 Lecture Note，再判断是否改变课程地图或方法论知识库。
3. 区分老师原意、我们的提炼和项目应用，避免把延伸理解写成课堂原话。
4. 稳定结论进入方法论；尚未验证的判断保留为开放问题或实验。
5. 课程方法最终应在 PFMEA Agent 等真实项目中接受验证，而不是直接照搬。
