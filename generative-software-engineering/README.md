# 生成式软件工程学习实验室

这里不是课程摘要的堆积，而是一套持续演进的学习与实践系统。

课程主线是：如何把人的 **Intent**，通过 **Specification、Architecture、Context、Execution、Verification、Versioning**，稳定地转化为可演进的软件。

## 三份活文档

- **课程地图**：回答课程整体在讲什么、每一课位于哪里。
- **知识库**：保存可复用的 Principle、Method、Pattern、Anti-pattern 和 Skill 候选。
- **学习日志**：记录认识如何变化、做了什么决策，以及下一步如何验证。

## 与 PFMEA Agent 的关系

生成式软件工程是上位方法论层；PFMEA Agent 是应用和验证层。课程中关于意图、规格、复杂性、事实、操作、派生状态、证据和版本管理的判断，需要通过 PFMEA 的真实业务链进行验证。
